# Surface project presets

Surface owns `surface-app`, `surface-desk` and the `surface-ui` layer in this
catalog. Folio's independent module in Substrate owns the renderer and generic
layers, including the single `agent-dir` used by `surface-desk`.

From a pinned Surface checkout, point Folio at this directory:

```sh
folio --preset-pack /path/to/pinned-surface/scaffolding preset list
folio --preset-pack /path/to/pinned-surface/scaffolding plan surface-desk ./example --input repo_name=example --non-interactive
```

Keep the Folio and catalog revisions with build inputs. Packs do not download
or select remote dependencies. ID, relative composition path and declared
version constraints are checked; duplicate preset directories fail. Manifests
record preset versions and logical paths, not catalog repository revisions.

This independent Go module tests rendering, generated byte digests captured
before relocation, title escaping, discovery, shared agent-directory output and
resolver compilation. `go vet ./...` and `go test -race ./...` run here. The
published-release install/build acceptance suite remains opt-in with
`FOLIO_SURFACE_ACCEPTANCE`; it can require npm and published Surface packages.
No active app files or dependency pins are changed by this source move.
